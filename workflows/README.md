# n8n Security Automation Workflows

This folder contains the n8n workflow exports developed for the **TaskFlow Security Automation Lab**.

**Project Creator:** Shubham Uniyal

**Note:** TaskFlow is an invented website and simulated environment created for cybersecurity automation training.

## Workflow Progress

| Workflow | Description | Status |
|---|---|---|
| LAB 00 — Upsert Security Task | Reusable task creation, deduplication, escalation, and notification workflow | Completed and tested |
| LAB 01 — Crypto Asset Discovery | Cryptographic inventory assessment and security task generation | In progress |
| LAB 02–08 | Additional security automation scenarios | Planned |

## How to Use

The workflow JSON files can be imported into a compatible n8n instance.

They depend on the local TaskFlow Mockoon environment and may require configuration before execution.

These workflows use simulated data and are not intended for direct production deployment.
